ProIngest

A working picture of the shot list the VFX editor drives, built to the interface spec. Every value on this page is invented sample data and the buttons only move this preview: nothing is scanned, rendered or written. Press Run to watch a batch go through.

What this is. A front-end mock of docs/UI_SPEC.md, kept in the repo so the layout can be argued about before it is built in Qt. The shipping application is PySide6, not a web page; the colours, columns, keyboard model and metadata pane here are the ones that spec describes. Shot codes, turnovers and shooter names are fictional.
